# davinci-resolve-mcp capability map

Not the vendor's README repeated — this is extracted directly from the
running code (`src/server.py`) on this rig via `mcp.list_tools()` +
docstring parsing, not the vendor README's advertised tool-level number
(granular mode exposes roughly one MCP tool per API method, whereas this
counts the compound server's internal `action=` values — a different unit).
See [README.md](README.md) for the install/validation context this
sits inside, and
[pipelines/mcp-benchmark/README.md](pipelines/mcp-benchmark/README.md) for
the live probes and real workflow tests run against this catalog — that's
where "does it actually work" evidence lives; this file is just the map.
